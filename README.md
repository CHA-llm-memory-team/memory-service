# Сервис долговременной памяти

Отдельное хранилище памяти для агентов на основе языковых моделей. Клиент создаёт деревья для пользователей, проектов и задач по мере необходимости. Количество деревьев заранее не задано. Словари помогают находить факты, а обычный код отвечает за версии, сроки действия, доступ и удаление.

Сервис предназначен для чужих агентов, прежде всего команд с темами 1, 2, 12, 13 и 14 курса. Пользу памяти измеряем по ответам после потока событий. Главная альтернатива — полная история с усечением. Извлечение и поиск берём из готовых средств или рассматриваем их как объекты сравнения: mem0, Zep, Letta. Собственный векторный поиск не пишем.
