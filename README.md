# Сервис долговременной памяти

Память для чужих агентов: хранение, поиск, пересмотр сведений и удаление по требованию.

Начать с [описания проекта](design_doc.md): там находятся контракт, бюджеты, архитектура и правила проверки КТ1.

- [20 историй с вопросами](eval/kt1_examples.jsonl).
- [Удаление](eval/deletion_cases.jsonl) и [отравление с обычными контрольными событиями](eval/poisoning_cases.jsonl) — части основного набора.
- [Настройки источников](eval/source_policy.json).
- Проверка файлов: `python eval/validate.py`.

КТ1: постановка задачи и проверочные данные. Реализация сервиса и сравнительные результаты пока не представлены.

[Требования курса](https://github.com/xufana/llm-system-engineering/blob/main/project.md).
